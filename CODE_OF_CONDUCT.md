# Code of conduct

Be kind, be direct, assume good intent. We welcome contributors of every background and
experience level.

Unacceptable: harassment, personal attacks, discriminatory language, publishing others'
private information, and sustained disruption of discussions.

Maintainers may edit, remove or reject contributions and comments that do not follow this
code, and may ban repeat offenders. Report problems privately to the maintainer through
GitHub (profile contact) or the private vulnerability reporting form if the matter is
security related.

This document is adapted from the spirit of the Contributor Covenant, version 2.1.
